# Security

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/orionshock/SecondPassReader-WebClient/security/advisories/new).
Include the affected commit or image tag, reproduction steps, and expected impact. Redact tokens,
credentials, and private Library content. Please avoid public issues for undisclosed vulnerabilities.

Security fixes target the current development branch and subsequent prereleases. Older development
images and prereleases do not receive separate backports; deploy a newly verified image to receive
fixes.
