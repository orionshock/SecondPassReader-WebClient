# Roadmap (phases)

1. **Init environment/docs** (this phase)
2. **Connection setup** (server URL + profile)
3. **Client auth linking flow** (discover → request → code/URL → poll)
4. **`/me` verification** (`GET /api/v1/accounts/me/`)
5. **Library landing page** (list/select books)
6. **Renderer sandbox** (ReaderBridge + minimal renderer integration harness)
7. **Book launch from library** (open selected book)
8. **Current location sync** (report/restore location via CFI)
9. **Highlight creation** (selection → Web Annotation JSON-LD draft → persist)
10. **Saved annotation rehydration** (load + render overlays)
11. **Later:** notes, bookmarks, layered sessions, richer annotation tools
